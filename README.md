<h4 class="text-center"><em>GAME</em></h4>
<p>You play as a station engineer named Peter, you are tasked to help the current engineers that are working in Primera B Station, an entertainment station built by Victory Entertainment. Your main priority is to fix whatever is wrong with the station and second is to figure out why the previous engineers hasn't made progress. All communications are cut, you are alone in this.</p>
